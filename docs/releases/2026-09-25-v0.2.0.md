# Bili Danmaku v0.2.0：自动识别、播放同步与样式增强

`v0.2.0` 在首个可用版本 `v0.1.5` 的基础上，加入弹幕源自动推荐/加载、更多弹幕样式设置，以及更准确的播放状态同步。

## 主要变化

- **弹幕源自动识别：** 根据本地文件名搜索可能匹配的番剧/视频，并展示排序后的推荐。番剧与视频自动加载开关相互独立且默认关闭；仅在目标唯一且高置信时自动加载，有歧义时交由用户选择。
- **异步加载更安全：** 通过文件、搜索和加载代际隔离过期响应；后台识别不会中断播放或清除当前弹幕流；来源切换时显示 HUD 状态。
- **播放状态同步：** 暂停/恢复、播放倍速、显式 seek 和时间偏移均同步到 overlay；时间轴不连续变化后按最终播放位置重建弹幕。
- **弹幕样式控制：** 可选择本机字体、调整描边宽度和颜色，样式偏好持久化；更新样式无需重启解析器/渲染器。
- **弹幕源面板改进：** 自动识别/推荐与手动搜索分区显示，可选择推荐的番剧集数或视频分 P。
- **流式处理与响应性：** 延续 XML 分块传输、ACK 背压、渐进解析/渲染和 Worker 回退，并改进搜索结果处理与过期请求隔离。

## 验证

- 自动化回归测试 `158/158` 通过，运行时 JavaScript 语法检查通过。
- 播放同步通过 IINA 1.4.4 倍速/暂停/seek 实机矩阵。
- 自动加载通过文件名识别覆盖和 IINA 在线自动加载/弹幕渲染实机验证。完整的快速切换文件逐阶段实机矩阵已豁免、未执行；相关行为由过期代际自动化测试覆盖。
- IINA 重启后样式偏好持久化已验证。字体/描边渲染的完整实机视觉验收已豁免、未执行；渲染与侧栏行为由自动化测试覆盖。

## 安装

从本 Release 下载 `iina-bilibili-danmaku-0.2.0.iinaplgz`，在 IINA 中选择 **设置 → 插件 → 本地安装** 并选中该文件，安装后重启 IINA。

插件将 B 站弹幕映射到本地视频；不播放、下载或代理 B 站视频。
