# Bili Danmaku v0.1.5：首个可用版本

`v0.1.5` 是 Bili Danmaku for IINA 的首个正式可用版本，可将哔哩哔哩普通视频或番剧弹幕映射到 IINA 正在播放的本地视频。

## 弹幕源

- 输入 BV 号或完整视频链接，读取视频标题、分 P 和对应弹幕。
- 搜索 B 站番剧，选择剧集与分集。
- 直接解析番剧 `ep`、`ss`、`md` 链接。
- 快速切换分 P、分集或来源时忽略旧请求响应并取消旧渲染流。

## 渲染与播放同步

- 支持滚动、逆向滚动、顶部和底部弹幕。
- 跟随当前播放时间，支持暂停、恢复、明显的前后跳转、窗口缩放和页面重新显示。
- 当前小于约 5.5 秒的向前跳转可能短暂保留跳转前的在屏弹幕，完整的显式 seek 与倍速同步已列入后续计划。
- 使用时间戳最小堆处理乱序弹幕，并保留已解析历史供后退跳转重建。
- 活动弹幕上限为 240，避免密集弹幕产生过多 DOM。
- 补齐 CommentCoreLibrary 所需的 `.abp` / `.container` 容器样式，保证白色描边弹幕正常显示。

## 控制与状态

- 支持弹幕显示开关、顶部/底部过滤、字号、透明度、滚动速度、时间偏移和清空。
- 设置通过 IINA preferences 持久化，并可在加载后实时生效。
- 侧边栏显示下载、传输、解析、可显示、完成、空弹幕与错误状态。
- 区分视频不存在、权限限制、B 站风控、HTTP 失败、空弹幕和渲染失败。

## 大型弹幕性能

- `main.js` 以 128 KiB 分块传输 XML，并通过逐块 ACK 保证最多一块在途。
- Worker 流式解析并按最多 200 条一批渐进交给渲染层，首批可用后立即显示。
- WKWebView 的 `file://` 页面无法加载 Worker 时，自动回退到 16 KiB 时间片解析并重放未确认块。
- 普通播放时间 IPC 最多每 33ms 一次，避免高频跨 WebView 通信。
- 合并相同关键词的并发搜索，并在 JSON 解析前丢弃过期响应。

## B 站数据兼容

- 支持现代 9 参数及更多参数的弹幕记录。
- 兼容超出 `Number.MAX_SAFE_INTEGER` 的 64 位 `dbid`，与 CCL 的 `parseInt` 语义一致。
- 支持 XML 实体、换行归一化和常见字符转换。
- 跳过格式异常记录与 mode 7/8/9 的高级、代码、BAS 弹幕，不中断整条弹幕流。
- 所有请求带 Referer 与浏览器 UA，搜索使用持久化随机 `buvid3` 降低 `-412` 风控概率。
