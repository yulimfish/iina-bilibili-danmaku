# Bili Danmaku v0.3.0：扫码登录与历史弹幕

`v0.3.0` 在 `v0.2.0` 的弹幕源识别、播放同步和样式控制基础上，增加可选 B 站登录与历史弹幕补充，同时保留匿名加载。

## 主要变化

- **可选登录：** 支持本机二维码扫码或粘贴 Cookie/SESSDATA。新验证的 SESSDATA 存入 macOS 钥匙串；升级时会迁移旧版设置中的凭据，只有钥匙串写入并读回成功后才清理旧值。迁移失败时保留旧设置以避免丢失，并回退匿名模式。
- **账号权益状态：** 登录后显示 B 站账号昵称、大会员状态/类型及有效期；未登录时说明匿名模式仍可加载当前弹幕池，但无法回补历史弹幕。
- **历史弹幕补充：** 登录后加载来源时按日期限速请求历史弹幕，显示进度并支持取消；采用有限回补预算，不保证覆盖 B 站页面统计。历史结果失败或取消不阻断当前弹幕播放。
- **匿名兼容：** 保留无需登录时的当前弹幕加载路径，登录接口或历史接口异常时尽量继续使用匿名弹幕。
- **来源与切换修复：** 普通弹幕池可合并匿名数据；切换文件后的 overlay 重载握手更可靠；番剧结果优先显示正片。
- **本机二维码：** 使用本地 vendored QR 编码器，不依赖第三方页面生成登录码。

## 安装

从本 Release 下载 `iina-bilibili-danmaku-0.3.0.iinaplgz`，在 IINA 中选择 **设置 → 插件 → 本地安装** 并选中该文件，安装后重启 IINA。

插件将 B 站弹幕映射到本地视频；不播放、下载或代理 B 站视频。
